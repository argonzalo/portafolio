# Listado de proyectos

Las imagenes de los proyectos se encuentran en ´/public/images/proyects´. Cada proyecto tiene su propia carpeta. Si el proyecto cuenta con subproyectos, cada subproyecto tiene su carpeta.
Si algún proyecto no tiene imagen, se debe utilizar un fallback con la letra inicial del proyecto en mayúsculas.

* Orden de proyecto: Indica la posicion de la tarjeta del proyecto en la grilla.
* Orden de subproyecto. Cuando hay mas de un proyecto dentro de otro (subproyectos), se indica el orden en que se acomodan los subproyectos en las tabs / selectores. Se debe usar la primera imagen del subproyecto
número 1 como portada de la tarjeta del proyecto.

## Banner Director
- Clave: banner-director
- Orden: 1
- Titulo: Banner Director
- Empresa: Banner Director
- Descripcion tarjeta: Software de gestión y distribución de contenido digital para cartelería de forma centralizada.
- Fecha: 2021 - 2026
- Stack: GO, Vue, PostgreSQL, TypeScript, Kotlin, Docker, Next, Firebase, Kubernetes.
- Descripcion empresa/proyecto: Plataforma de Digital Signage que permite gestionar de forma centralizada el contenido de miles de pantallas en múltiples locales. Actualmente cuenta con casi 10.000 equipos activos y clientes como Grido, Açaí, Marea, Diarco y Leroma, entre otros.
- Ubicacion: Córdoba, Argentina

### Subproyectos
- Clave: banner-2
- Orden: 1
- Titulo: Banner 2.0
- Fecha: 2023 - 2026
- Stack: GO, Vue, PostgreSQL, TypeScript, Kotlin, Docker, Kubernetes.
- Descripcion proyecto: Sistema de Digital Signage para grandes franquicias, basado en tres pilares: interfaz gráfica en Vue, con un potente editor visual para crear y gestionar contenido; backend en Go y base de datos PosgreSQL, y Android / Kotlin, para la operación y reproducción de contenido en los equipos. El sistema permite administrar contenidos con configuraciones avanzadas por regiones, fechas, entidades, etc.
- Url: https://v2.bannerdirector.com
- Datos: +600 equipos funcionando
