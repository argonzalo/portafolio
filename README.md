# Portfolio

Sitio personal construido con Astro, TypeScript, Tailwind CSS, MDX, shadcn/ui, GSAP y Three.js.

## Desarrollo

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — build de producción
- `npm run preview` — previsualizar el build
- `npm run lint` — ESLint
- `npm run typecheck` — comprobación de tipos con Astro
