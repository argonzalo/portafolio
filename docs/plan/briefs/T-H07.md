# Brief — T-H07 Datos reales de Vibo (overlays + métricas)

> Insumo humano (I-02). Dirección creativa: ADR-011.

## Objetivo

Dejar en `assets-src/vibo/` un paquete anonimizado listo para que T-A14-vibo / T-A20 armen overlays de detección creíbles y una tarjeta de métricas, **sin** pretender reconstruir una trayectoria 3D fiel.

## Contexto necesario

- Ficha: `03-escenas.md` §3.1.
- Decisión: ADR-011 en `decisiones.md`.
- Insumo: `05-contenido.md` I-02.

## Alcance

- Incluye:
  - Acceso al proyecto Firebase **vibo-beta** (id `vibo-beta-2e60f`).
  - Elegir 1–2 documentos de la colección `videos` con `analysisResults` útiles (al menos un golpe claro).
  - Exportar el JSON crudo (o un subconjunto) a `assets-src/vibo/reference/` (gitignored; no subir PII).
  - Curar un JSON de escena en `assets-src/vibo/overlays/` con la **ventana del golpe**: bounding boxes, pose keypoints y etiquetas útiles para HUD flotante, frame a frame o muestreado.
  - Un set de **métricas de jugador anonimizadas** (estilo, golpes frecuentes, etc.) en JSON para el beat Resultado.
  - Nota breve de permiso / anonimización en `docs/plan/licencias.md` (o comentario en el README de la carpeta).
- No incluye:
  - Reconstrucción 3D de cancha/pelota/jugador a partir del tracking.
  - Modelo o animación del personaje (T-A20 / pipeline de assets).
  - Implementación de la escena.

## Zona de archivos

- Puede modificar: `assets-src/vibo/`, `docs/plan/licencias.md` (permiso), y si hace falta una línea en el estado de I-02 del tablero.
- No debe tocar: `src/scenes/`, contratos, dependencias.

## Contratos que usa o expone

Ninguno de runtime aún. El JSON curado debe ser estable y documentado en un `assets-src/vibo/README.md` (campos, unidades, origen de coordenadas: imagen / normalizado 0–1, etc.) para que T-A20 lo consuma sin adivinar.

## Criterios de aceptación

- [ ] Hay al menos un clip de referencia exportado y un JSON de overlays centrado en un golpe.
- [ ] Métricas de jugador sin nombres, IDs ni datos personales identificables.
- [ ] README en `assets-src/vibo/` explica origen (Firebase), limitaciones (perspectiva de cámara) y esquema del JSON curado.
- [ ] Tablero: I-02 pasa a estado usable (nota “listo para T-A20” o equivalente).
- [ ] No se exige ni se entrega trayectoria 3D fiel (ADR-011).

## Cómo verificar

Abrir el JSON de overlays y confirmar que en ~1–2 s de lectura se ve una secuencia de golpe con cajas/keypoints; abrir métricas y confirmar que no hay PII. El orquestador marca I-02 avanzado en el tablero.
