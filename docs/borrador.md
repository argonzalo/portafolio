Por carga de **diseño + modelado 3D**, ordenados de más a menos exigentes:

### Nivel alto (los que más te van a pedir)

| Ticket | Por qué |
| --- | --- |
| **T-A24 — Naturalis** | Es la escena con **más modelado real**: sala en Blender, lightmaps horneados, plantas/macetas/camilla/cortina, ciclo día/noche. El plan la marca explícitamente como la de mayor costo de assets. |
| **T-H09** (insumo humano) | Quien aporta o elige esos assets de Naturalis. Si modelás vos, es el ticket de modelado más pesado del lado humano. |
| **T-A19 — Kit de dispositivos** | Teléfono, notebook y display low-poly con UI flotante. Se reutiliza en casi todo; si sale mal, arrastra a Naturalis, Banner, satélites y viñetas. |
| **T-A20 — Vibo completa** | Más **diseño de escena + motion/shaders** que modelado pesado (cancha procedural, jugador por keypoints). Alta dirección de arte e interacción; modelado medio salvo que uses Mixamo/silueta. |
| **T-A25 — Banner 2.0** | Menos “muebles en Blender”, más **diseño técnico 3D**: instancing de miles de pantallas, mapa, sala de control, uso del kit. |
| **T-A23 — Pirp** | Sobre todo **dirección visual + sistemas** (atlas de titulares, grafo, torrente). Poco modelado tradicional; mucho diseño de movimiento y composición. |
